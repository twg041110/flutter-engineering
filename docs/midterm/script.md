# 중간발표 대본 (약 1분 10초)

장표: `slide.png` 1장 (왼쪽부터 ① 내역 · ② 홈 · ③ 입력)
`[ ]` 안은 행동이고, 소리 내어 읽지 않는다.

---

**[인사]**
안녕하세요, ○○○입니다. 제가 만들 앱은 **"후회 지출 가계부"**입니다.

**[문제]**
저는 월말이 되면 돈이 부족한데, 어디에 썼는지 기억이 나지 않습니다.
가계부를 써도 숫자만 쌓이고, 무엇을 줄여야 할지는 알 수 없었습니다.

**[핵심 가치]** `[① 내역 화면]`
그래서 이 앱의 핵심은 **아까웠던 지출에 "후회"를 표시하는 것**입니다.
결제할 때는 몰라도 다음 날 보면 아까운 경우가 많아서, 후회는 나중에 돌아보며 누르게 했습니다.
내역에서 지나고 보니 아까운 지출에 후회 버튼을 누르면, 이번 달 후회 금액 **4만 5천 원**과 줄일 수 있는 돈 중 **23%**가 바로 보입니다.

**[홈]** `[② 홈 화면]`
홈에서는 남은 돈 아래에 후회 금액을 다시 보여 주고, 오른쪽 위 화살표로 지난달도 돌아볼 수 있습니다.

**[입력]** `[③ 입력 화면]`
기록은 금액과 카테고리만 고르면 끝나고, 없는 카테고리는 + 로 직접 만들 수 있습니다.

**[마무리]**
이 앱은 쓴 돈을 적는 데서 끝나지 않고, **어디서 돈이 새는지** 알려 주는 가계부입니다. 감사합니다.
